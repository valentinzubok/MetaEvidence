# Portal — MetaEvidence (Intelligent Contracts)

**Type:** Builder → Intelligent Contracts  
**Title:** MetaEvidence — JSON schema audit passport for AI models and APIs

## Description (paste)

```text
MetaEvidence registers JSON schemas for external resources, attaches metadata + SHA-256 data_hash, and audits compliance under eq_principle_strict_eq (required fields, types, hash match).

Lifecycle: pending_audit → valid | invalid. Events: SchemaRegistered, EvidenceAttached, AuditPerformed, AuditResult.

Use case: public “passport” for AI model cards, API version claims, dataset manifests — independent of publisher code.

GitHub: https://github.com/valentinzubok/MetaEvidence
```
